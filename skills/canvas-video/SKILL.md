# canvas-video

A video here is a folder with a tiny `index.html`, a `script.json` (scenes + what is
said), and a `scenes.js` (one drawing function per scene). A shared `engine/` folder
next to it provides the player and the drawing helpers. Narration is generated
offline; **the voice sets the timing** and the animation hooks onto sentences.

```
<videos-root>/
  engine/            engine.js, player.css, fonts/   (copied once from this skill)
  my-video/
    index.html       loads ../engine/engine.js, timing.js, scenes.js
    script.json      scenes, chapters, sentences per language   ← you write
    lexicon.json     pronunciation fixes                          ← you write
    scenes.js        scene(t, d, cues) functions + VIDEO.create() ← you write
    timing.js        GENERATED by narrate.py
    audio/<lang>.m4a GENERATED by narrate.py
```

All scripts live in this skill's `scripts/` folder (paths below are relative to the
skill directory). They run with `uv` and install nothing in the user's project.
Prerequisites: `ffmpeg`, `uv`; Chrome or `uvx playwright install chromium` for stills/MP4.

## Workflow

Follow these steps in order. Do not skip step 6 (looking at your own output).

### 1. Gather facts — never invent

Read the project's README, docs, changelog, benchmarks, and the code of the feature.
Note the **current** numbers with their test conditions; prefer measured results over
marketing copy (GitHub descriptions and old blog posts are often stale — check).
Note the visual identity: colours, fonts, logo (a `DESIGN.md`, CSS variables, the
docs site theme). If something is opt-in or experimental, the video must say so.

### 2. Propose a storyboard, get it approved

6–8 scenes for ~60–90 s; one idea per scene; ~20–25 words of narration per scene
(≈150–190 words per minute of speech). Show the user a table: scene id, what is on
screen, the sentences. Wait for approval before building. For a series, propose the
episode list first.

### 3. Scaffold

```bash
python3 scripts/new_video.py <videos-root>/<name> --title "…" --langs en,fr
```

Pick `<videos-root>` with the user: `docs/videos/` (served by GitHub Pages / MkDocs),
`static/videos/` (Hugo), `public/videos/` (Vite/Next)… anything served as static files.
The template plays as-is once narrated — narrate it first to prove the toolchain works.

### 4. Write `script.json`

```json
{"langs": ["en", "fr"],
 "scenes": [
   {"id": "problem", "min": 6, "lead": 0.8, "chapter": {"en": "The problem", "fr": "Le problème"},
    "en": ["First sentence.", {"text": "Not before 3 s into the scene.", "at": 3.0}],
    "fr": ["Première phrase.", "Deuxième."]}]}
```

- One sentence per cue: each cue becomes a subtitle and an animation hook.
- **Write numbers, units and symbols in words** ("ten thousand", "sixty-five percent",
  "less than a millisecond"): engines misread "10,049" (comma = decimal in French).
- Scene keys: `min` (minimum seconds), `lead` (silence before speech, default 0.5),
  `tail` (after, default 0.6), `chapter` (adds a chapter marker).
- Optional top level: `"engine": "kokoro"` and `"voices": {"kokoro": {"en": {"voice": "am_michael"}}}`.

### 5. Narrate

```bash
uv run --with kokoro-onnx --with soundfile scripts/narrate.py <videos-root>/<name>
```

First time only: `python3 scripts/narrate.py --download-model` (Kokoro, ~340 MB).
For a quick draft voice with no download: `--engine say` (macOS) or `--engine espeak`.
Then **check pronunciation with the `narration-lexicon` skill** (same plugin): it
transcribes every sentence with Whisper and tells you which words to fix.

### 6. Write the scenes, then look at them

Read `references/engine-api.md` for the helpers and `references/scene-recipes.md`
for proven patterns. The rules:

- **A scene is a pure function of `t`**: no `Math.random()` (use `rng(seed)`), no
  `Date.now()`, no state kept between frames. Same `t` → same pixels.
- **Hook animations onto sentences**, not seconds: `const a1 = at(cues, 1, 4)` is the
  start of sentence 2 (fallback 4 s). This keeps every language in sync.
- 1280×720 logical canvas; keep text inside x∈[80, 1200]; the bottom 40 px hold the
  progress line; leave room for subtitles (y > 600) in busy scenes.
- Put every on-screen string in `STR[lang]` and use `S.key` (English is the fallback).
- Use the project's palette via `theme` in `VIDEO.create`, and a custom `background`
  if the identity calls for it. Set `poster` to the scene that best sums up the video.

Then **render a contact sheet for every language and read the images back**:

```bash
uv run --with playwright scripts/render.py <videos-root>/<name> --sheet
```

It writes `build/video/<name>-<lang>-720p-sheet.png` (the last second of every
scene). Check: overlapping elements, text overflowing in the longest language,
empty or half-built frames, labels colliding with bars, ligatures in code
(`--` rendered as `—`). Fix and re-render until clean. For a precise moment:
`--still 12.5`.

### 7. Ship

- **Embed** on any page (16:9 stage + 40 px control bar):

  ```html
  <div style="container-type:inline-size">
  <iframe src="/videos/<name>/?embed=1&lang=en" title="…" loading="lazy" allow="fullscreen; autoplay"
          allowfullscreen style="display:block;width:100%;height:calc(56.25cqw + 40px);border:0"></iframe>
  </div>
  ```

  URL parameters: `lang`, `t` (start time), `subs=1`, `autoplay=1`, `embed=1`.
- **CI**: `python3 scripts/narrate.py --check <videos-root>` (stdlib only) fails when a
  script, voice or lexicon changed without re-narrating. Suggest adding it.
- **MP4** only where JavaScript can't run (YouTube, LinkedIn, release assets):
  `uv run --with playwright scripts/render.py <videos-root>/<name> --lang en [--burn-subs]`.

## Voices and licences

The default engine is Kokoro (Apache-2.0 weights: publishable, commercial included;
excellent in English, weaker French/Italian voices). Before publishing, make sure the
user may publish the audio of the engine they picked — read `references/tts-engines.md`.
Two traps to always mention: **macOS `say` output must not be published** (Apple SLA
§2F), and **edge-tts is an unlicensed private endpoint** (and returns 403 in the EU
since Oct 2026). Azure AI Speech's free tier (`--engine azure`) offers the same
Microsoft voices, licensed.

## Series

For several videos in one place: share one `engine/`, keep each episode
self-contained, and avoid shared registries that every episode must edit (parallel
agents will conflict on them). A gallery page can simply iframe each `?embed=1`.
